MilkDrop presets that come with Spotiamp+ (the list is in CREDITS.txt).
Each one is by the author named at the start of its file name. The Incubo_
folder holds presets by Incubo_ (Se7enSlasher), shared with Spotiamp+ by him.
Classic MilkDrop presets were released freely, without a specific licence; if
you made one of these and want it out, open an issue at
github.com/fdeox/spotiamp-plus.
Your own presets go in %APPDATA%\spotiamp\config\milkdrop (right-click the
MilkDrop picture: Open the presets folder).
